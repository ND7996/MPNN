GPX6 Sequence Exploration Using ProteinMPNN
Overview

This project explores potential evolutionary variants of GPX6 (Glutathione Peroxidase 6) using the deep learning–based protein design tool ProteinMPNN developed by the Baker Lab.

The aim is to identify novel amino acid sequences that are compatible with the GPX6 backbone structure. By exploring the surrounding sequence space, this approach seeks to uncover mutations that may enhance catalytic activity, improve structural stability, or provide insight into possible evolutionary adaptations of GPX6.

Workflow

Prepare the Structure
Obtain and prepare the GPX6 backbone structure in PDB format.

Run Sequence Design
Use ProteinMPNN to generate sequences compatible with the fixed GPX6 backbone.

Generate Candidate Sequences
Sample multiple sequence variants to explore diverse possibilities within the GPX6 sequence space.

Rank the Designs
Evaluate and rank generated sequences based on model confidence scores.

Analyze Mutations
Examine the resulting mutations, focusing on functional regions and residues that may influence enzyme activity or stability.
